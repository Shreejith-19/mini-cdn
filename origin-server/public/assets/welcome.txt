=========================================
  MINI CDN SIMULATOR - ORIGIN STATIC ASSET
=========================================

Content Delivery Networks (CDNs) distribute web content to edge nodes
positioned strategically around the globe close to users.

When a user requests this file:
1. The CDN router directs the client to the optimal edge server.
2. If the edge has this file in-memory (CACHE HIT), it returns instantly.
3. If not (CACHE MISS), the edge fetches it from this Origin Server (:8000),
   caches it locally, and serves it to the user.

Subsequent requests from that region bypass the origin completely!
